## Giới hạn kết quả và tài liệu chạy lại

H2 không thay thế việc kiểm tra PostgreSQL/MySQL thật: chưa xác minh migration, JSON column, transaction/lock đặc thù DB production. MinIO tắt nên upload thành công chỉ xác minh storage local; chưa xác minh bucket, presigned URL, hết hạn link và chính sách production. Chưa chạy load test k6, benchmark hiệu năng, kiểm tra nhiều thiết bị/browser thực hoặc độ chính xác vật lý 3D. Smoke test route kiểm tra tải/render và lỗi phát sinh ban đầu, không bao phủ mọi nút/chức năng ở 52 trang.

Log SQL có unique-constraint error trong các test concurrency; các test đó vẫn đạt điều kiện xử lý cạnh tranh. Không phân loại mọi dòng ERROR trong log thành lỗi test.

Các server và browser riêng được dừng sau kiểm tra; H2 trong RAM mất dữ liệu khi dừng. Bản sao backend và harness đủ để dựng lại fixture. Hướng dẫn: [harness/README.md](harness/README.md).

Kết quả có cấu trúc: [test-summary.json](test-summary.json), [backend-test-summary.json](backend-test-summary.json), [backend-probes.json](backend-probes.json), [live-ui-results.json](live-ui-results.json), [lifecycle-results.json](lifecycle-results.json). Không đưa log thô chứa JWT vào báo cáo.

Thứ tự xử lý đề xuất: kiểm tra quyền theo lớp → sửa multipart JSON và giữ assignmentId → kiểm tra rubric và điều kiện chốt ở backend → cung cấp mô phỏng hoạt động → sửa dropdown giao lớp, override hướng dẫn và thông báo lỗi → cập nhật fixture/test regression rồi chạy lại.
