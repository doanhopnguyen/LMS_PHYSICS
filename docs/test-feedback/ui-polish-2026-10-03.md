# Báo cáo rà soát giao diện theo flow.md

Ngày thực hiện: 03/10/2026.

Giữ nguyên màu đỏ chủ đạo, font Be Vietnam Pro, header/sidebar, hệ thống card, bảng, icon và điều hướng hiện có. Các thay đổi tập trung vào component dùng chung, khoảng cách và câu chữ. Không đổi API, routing, dữ liệu gửi lên hay quy tắc phân quyền.

## Component và style đã chỉnh

| File/component | Thay đổi |
| --- | --- |
| `FormField.jsx`, `styles.css` | Sửa thứ tự ưu tiên CSS khiến ô nhập bị padding bằng 0; đệm ngang 16px, giữ utility chừa chỗ cho icon; nhãn, placeholder, viền, focus, disabled và invalid dễ đọc hơn. |
| `Tabs.jsx`, `styles.css` | Thêm prop `filters` để bộ lọc có vùng riêng; tab nằm một hàng cuộn ngang, khoảng cách và dấu chọn gọn hơn. |
| `SelectField` qua `styles.css` | Select trong form đặt nhãn phía trên; select trong toolbar giữ nhãn bên cạnh, chiều rộng thích ứng. |
| `AcademicFilters.jsx` | Cho bộ lọc và thao tác xuống hàng hợp lý khi màn hình hẹp; bỏ min-width gây ép chiều rộng. |
| `DataTable.jsx`, `styles.css` | Giữ header đỏ và hàng xen kẽ hiện có; thêm viền/phân cách, điều chỉnh độ rộng, xuống dòng nội dung dài và cột thao tác; bảng nhiều cột cuộn trong vùng bảng trên điện thoại. |
| `StatusBadge.jsx` | Thêm trạng thái và màu ngữ nghĩa dùng chung: duyệt/hoàn tất màu xanh, chờ màu vàng, lỗi/khóa màu đỏ, nháp/ngừng màu trung tính. Prop tone cũ vẫn dùng được. |
| `Button.jsx`, `SectionHeader.jsx` | Nút không co chữ/đổi dòng tùy tiện; tiêu đề và thao tác wrap với khoảng cách nhất quán. |
| `FormDialog.jsx` | Backdrop làm rõ popup; padding thích ứng, tiêu đề dài xuống dòng, nút đóng giữ kích thước, nội dung dài cuộn trong popup. |
| `StudentSearchField.jsx`, `DashboardCalendar.jsx` | Chuẩn hóa lời hướng dẫn bằng tiếng Việt dễ hiểu. |
| `styles/tokens.css`, `account.css`, `authoring.css`, `header.css` | Dùng token khoảng cách/chiều cao control, tăng độ rõ của placeholder và thời gian thông báo, thu gọn nhóm thao tác tài khoản. |
| `lib/lecturerUtils.js` | Bổ sung nhãn tiếng Việt cho trạng thái, vai trò, loại đề/câu hỏi và các hoạt động phổ biến; mã dữ liệu vẫn giữ nguyên. |

## Kết quả kiểm tra

- Đọc và lập danh sách 60 file page; kiểm tra trình duyệt đủ 52 route đăng ký trong `App.jsx`.
- 1440px, 1280px, 768px và 390px: 208 lượt trang, 340 trạng thái gồm các tab. Không phát hiện tràn trang, tab xuống nhiều hàng hoặc lỗi JavaScript trong bộ dữ liệu kiểm tra.
- Số lần phát hiện ô nhập có đệm trái dưới 8px giảm từ 86 xuống 0. Đây là số lần quan sát theo trang/kích thước/tab, không phải 86 component riêng biệt.
- Hàng toolbar trang phân tích giảng viên tại 1280px giảm từ 129px xuống 45px; bộ lọc được đặt bên dưới với grid riêng.
- Bổ sung dữ liệu mẫu cho 22 route ở bốn kích thước: 88 lượt trang, 176 trạng thái, gồm bảng/card có dữ liệu và một số popup.
- Mở đủ bảy loại form tạo (tài khoản, học kỳ, câu hỏi quản trị, học liệu, câu hỏi giảng viên, đề thi, thí nghiệm) ở 1280px và 390px: 14 lượt popup, 48 trạng thái tổng cộng. Không phát hiện tràn vùng chính hoặc thiếu padding.
- Đã xem ảnh đại diện desktop/mobile, gồm bảng câu hỏi, học liệu, form tạo, báo cáo thí nghiệm và phân tích.
- `node --test scripts/*.test.mjs`: 56/56 bài kiểm tra đạt.
- `node scripts/check-evidence-preview.mjs`: đạt; chỉ tải khi nhấn xem, JSON trình bày trong box/bảng, popup minh chứng riêng, ảnh/PDF, tải tệp, retry, focus/Escape và mobile.
- `node scripts/check-experiment-grading.mjs`: đạt; chọn bài nộp, số liệu/minh chứng, lưu điểm 0, kiểm tra giới hạn, phục hồi lỗi, xác nhận và trạng thái chỉ đọc; trợ giảng giữ nguyên quyền và luồng chấm.
- `node scripts/check-admin-pages.mjs`: đạt; 52 route không trắng trang/lỗi runtime/nested label, bảng đỏ giữ nguyên, dialog focus/Escape và form cấu hình vẫn gửi đúng dữ liệu.
- `npm run build -- --outDir .tmp-ui-polish-build`: đạt. Thư mục build tạm được dọn sau kiểm tra.
- `git diff --check`: đạt. Repo chưa có script lint/typecheck riêng; không ghi nhận hai bước này là đã chạy.

Các kiểm tra trình duyệt dùng API và tệp giả lập, không ghi vào backend. Chúng xác minh frontend và luồng đã nêu; chưa thay cho kiểm tra tích hợp với dữ liệu thật. Việc rà soát mã nguồn bao gồm file cũ không được route hiện tại sử dụng; danh sách route bên dưới thể hiện chính xác các màn hình đã mở.

## Vấn đề còn lại

Không phát hiện lỗi bố cục mới trong các trạng thái đã kiểm tra. Build vẫn cảnh báo bundle JavaScript vượt 500kB; bộ test API vẫn cảnh báo khóa `files` lặp trong `apiClient.js`. Hai cảnh báo đã có trước đợt chỉnh UI và không được xử lý trong phạm vi này. Các mã enum chưa có nhãn trong hệ thống vẫn dùng fallback hiện có.
